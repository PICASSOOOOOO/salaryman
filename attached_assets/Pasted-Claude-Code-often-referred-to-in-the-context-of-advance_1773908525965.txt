Where to Use Claude Code
Terminal/CLI (Recommended): The primary interface is the Command Line Interface (CLI).
VS Code / Cursor Extension: A VS Code extension is available, acting as a launcher for the terminal interface, making it easy to open in multiple panes.
Web Interface (Beta): You can use it at claude.ai/code, which runs in an Anthropic-managed virtual machine.
Desktop App: A dedicated desktop app for macOS and Windows is available for visual diff reviews.

How to Install and Use Claude Code
1. Installation
macOS and Linux (Native): Run this command in your terminal:
bash
curl -fsSL https://code.claude.com | bash
Windows (PowerShell): Run this command:
powershell
irm https://code.claude.com | iex
Verify Installation: Run claude --version.

3. Basic Usage (Terminal)
Once inside a project directory, you can interact with Claude using plain English. 
Start a session: Type claude and press Enter.
Ask for help: claude "fix the bug in the login component".
Reference a file: Use @filename to give context, e.g., claude "add validation to @src/auth.ts".
Run a one-time command: claude -p "Explain this function".
Create a commit: claude commit -m "Add authentication logic".

4. Pro Tips and Best Practices
Use /clear often: To prevent context fatigue and save token usage, run /clear between new tasks.
Permission Control: Claude asks before editing files. To speed up, use claude --dangerously-skip-permissions (use with caution).
Stop the Agent: Press Escape to stop Claude from working on a task.
Use CLAUDE.md: Create a CLAUDE.md file in your project root to provide instructions on coding standards, linting, and testing.
GitHub Integration: Use /install-github-app to enable automated PR reviews.

Key Differences from Standard ChatGPT
File System Access: Claude Code reads and edits your local files directly, unlike ChatGPT, which usually requires copy-pasting code snippets.
Agentic Behavior: Claude Code can plan, write, and run tests autonomously.
Project Context: It maintains awareness of your entire folder structure, not just the current file.
