# Nano Banana 2 API Documentation

> Submit a new Nano Banana 2 image generation or editing task

## Overview

This document describes how to use the Nano Banana 2 model for content generation. The process consists of two steps:
1. Submit a new Nano Banana 2 image generation or editing task
2. Query the status and results of a Nano Banana 2 generation task by task ID

## Authentication

All API requests require a Bearer Token in the request header:

```
Authorization: Bearer YOUR_API_KEY
```

Get API Key:
1. Visit [API Key Management Page](https://apipass.dev/app/api-keys) to get your API Key
2. Add to request header: `Authorization: Bearer YOUR_API_KEY`

## 1. Create Task

### API Information
- **URL**: `POST https://api.apipass.dev/api/v1/jobs/createTask`
- **Content-Type**: `application/json`

### Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| model | string | Yes | The model name to use for generation Example: `"google/nano-banana-2"` |
| callBackUrl | string | No | Callback URL for task completion notifications. If omitted, no callback will be sent. Example: `"https://your-domain.com/api/callback"` |

### Model Parameter

The `model` parameter specifies which AI model to use for content generation.

| Property | Value | Description |
|----------|-------|-------------|
| **Format** | `google/nano-banana-2` | The exact model identifier for this API |
| **Type** | string | Must be passed as a string value |
| **Required** | Yes | This parameter is mandatory for all requests |

> **Note**: The model parameter must match exactly as shown above. Different models have different capabilities and parameter requirements.

### Callback URL Parameter

The `callBackUrl` parameter allows you to receive automatic notifications when your task completes.

| Property | Value | Description |
|----------|-------|-------------|
| **Purpose** | Task completion notification | Receive real-time updates when your task finishes |
| **Method** | POST request | The system sends POST requests to your callback URL |
| **Timing** | When task completes | Notifications sent for both success and failure states |
| **Content** | Query Task API response | Callback content structure is identical to the Query Task API response |
| **Parameters** | Complete request data | The `param` field contains the complete Create Task request parameters, not just the input section |
| **Optional** | Yes | If not provided, no callback notifications will be sent |

**Important Notes:**
- The callback content structure is identical to the Query Task API response
- The param field contains the complete Create Task request parameters
- If callBackUrl is not provided, no callback notifications will be sent
- Credit consumption is based on the output resolution: 1K = 10 credits, 2K = 15 credits, 4K = 22 credits
- When image_search is enabled, google_search is also activated automatically

### input Object Parameters

#### prompt
- **Type**: `string`
- **Required**: Yes
- **Description**: A text description of the image you want to generate
- **Default Value**: `"A serene alpine lake reflecting snow-capped mountains at golden hour, photorealistic"`

#### image_input
- **Type**: `array(URL)`
- **Required**: No
- **Description**: Input images to transform or use as reference. Supports up to 14 images.
- **Accepted File Types**: image/jpeg, image/png
- **Max File Size**: 30MB per image
- **Default Value**: `["https://example.com/reference.jpg"]`

#### aspect_ratio
- **Type**: `string`
- **Required**: No
- **Description**: Aspect ratio of the generated image. Defaults to match_input_image when image_input is provided, otherwise 1:1.
- **Options**:
  - `match_input_image`: Auto (match input)
  - `1:1`: 1:1
  - `1:4`: 1:4
  - `1:8`: 1:8
  - `2:3`: 2:3
  - `3:2`: 3:2
  - `3:4`: 3:4
  - `4:1`: 4:1
  - `4:3`: 4:3
  - `4:5`: 4:5
  - `5:4`: 5:4
  - `8:1`: 8:1
  - `9:16`: 9:16
  - `16:9`: 16:9
  - `21:9`: 21:9
- **Default Value**: `"16:9"`

#### resolution
- **Type**: `string`
- **Required**: No
- **Description**: Resolution of the generated image. Higher resolutions produce more detail but take longer to generate. Default: 1K.
- **Options**:
  - `1K`: 1K (~1024px)
  - `2K`: 2K (~2048px)
  - `4K`: 4K (~4096px)
- **Default Value**: `"1K"`

#### google_search
- **Type**: `boolean`
- **Required**: No
- **Description**: Enable Google Web Search grounding to generate images based on real-time information such as weather, sports scores, or recent events. Default: false.
- **Default Value**: `false`

#### image_search
- **Type**: `boolean`
- **Required**: No
- **Description**: Enable Google Image Search grounding to find web images as visual context for generation. When enabled, web search is also used automatically. Default: false.
- **Default Value**: `false`

#### output_format
- **Type**: `string`
- **Required**: No
- **Description**: Format of the output image. Default: jpg.
- **Options**:
  - `jpg`: JPG
  - `png`: PNG
- **Default Value**: `"jpg"`

### Request Example

```json
{
  "model": "google/nano-banana-2",
  "callBackUrl": "https://your-domain.com/api/callback",
  "input": {
    "prompt": "A serene alpine lake reflecting snow-capped mountains at golden hour, photorealistic",
    "image_input": [
      "https://example.com/reference.jpg"
    ],
    "aspect_ratio": "16:9",
    "resolution": "1K",
    "google_search": false,
    "image_search": false,
    "output_format": "jpg"
  }
}
```

### Response Example

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_12345678"
  }
}
```

### Response Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| code | integer | Status code, 200 for success, others for failure |
| message | string | Response message, error description when failed |
| data.taskId | string | Task ID for querying task status and results |

### Callback Notifications

#### Success Callback Example

```json
{
    "code": 200,
    "data": {
        "completeTime": 1755599644000,
        "costTime": 12,
        "createTime": 1755599632000,
        "model": "google/nano-banana-2",

        "resultJson": "{\"resultUrls\":[\"https://cdn.apipass.dev/results/nano-banana-2-output.jpg\"]}",

        "taskId": "task_12345678",

```

#### Failure Callback Example

    "data": {
        "completeTime": 1755599644000,
        "costTime": 0,
        "createTime": 1755599632000,

## 2. Query Task

### API Information
- **URL**: `GET https://api.apipass.dev/api/v1/jobs/recordInfo`
- **Parameter**: `taskId` (passed via URL parameter)

### Request Example

```
curl -X GET "https://api.apipass.dev/api/v1/jobs/recordInfo?taskId=task_12345678" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response Example

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_12345678",
    "state": "success",
    "model": "google/nano-banana-2",
    "createTime": 1755599632000,
    "completeTime": 1755599644000,
    "costTime": 12,
    "resultJson": "{\"resultUrls\":[\"https://cdn.apipass.dev/results/nano-banana-2-output.jpg\"]}"
  }
}
```

### Response Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| code | integer | Status code, 200 for success, others for failure |
| message | string | Response message, error description when failed |
| data.taskId | string | The task ID |
| data.state | string | Current task state: waiting / queuing / generating / success / fail |
| data.resultJson | string | JSON string containing resultUrls array with the generated image URL(s) |

### State Values

- waiting — Task received, waiting for processing
- queuing — Task is in the generation queue
- generating — Image is actively being generated
- success — Generation completed, results available in resultJson
- fail — Generation failed, see failCode and failMsg for details

---

## Usage Flow

1. **Create Task**: Call `POST https://api.apipass.dev/api/v1/jobs/createTask` to create a generation task
2. **Get Task ID**: Extract `taskId` from the response
3. **Wait for Results**: 
   - If you provided a `callBackUrl`, wait for the callback notification
   - If no `callBackUrl`, poll status by calling `GET https://api.apipass.dev/api/v1/jobs/recordInfo`
4. **Get Results**: When `state` is `success`, extract generation results from `resultJson`

## Error Codes

| Status Code | Description |
|-------------|-------------|
| 200 | Request successful |
| 400 | Invalid request parameters |
| 401 | Authentication failed, please check API Key |
| 402 | Insufficient account balance |
| 404 | Resource not found |
| 422 | Parameter validation failed |
| 429 | Request rate limit exceeded |
| 500 | Internal server error |
