# Minx City – Terminal HUD & Gameplay Update

### Sprint Task Breakdown

## EPIC 1 — Terminal HUD Overhaul

### Ticket 1.1 — Increase UI Readability

**Priority:** High

**Description**
The interface text across the Terminal HUD and menus is too small and difficult to read.

**Tasks**

* Increase global UI font size
* Ensure readability across all menus
* Test readability on different resolutions

**Acceptance Criteria**

* All Terminal UI text is clearly readable
* Fonts scale correctly across resolutions
* No UI clipping occurs after resizing

---

### Ticket 1.2 — Add “Boomer Mode”

**Priority:** Medium

**Description**
Add a mode that replaces video-game terminology with practical real-world terminology.

**Tasks**

* Create a toggle for **Boomer Mode**
* Replace jargon with functional labels
* Maintain identical functionality

**Acceptance Criteria**

* Feature names change when Boomer Mode is enabled
* No gameplay systems are affected

---

### Ticket 1.3 — Terminal HUD Data Display

**Priority:** High

**Description**
Important player information is missing from the Terminal HUD.

**Add the following fields:**

* Salary
* Net Worth
* Current Map Location

**Acceptance Criteria**

* Values update in real time
* Data persists between sessions

---

### Ticket 1.4 — World Tab Time Zone Dropdown

**Priority:** Medium

**Description**
Replace the **World** tab with a timezone dropdown system.

**Requirements**

* Support 24 global time zones
* Each timezone linked to a region/city

**Current Implementation**

* Only display:

  * **Minx City (PST)**

**Acceptance Criteria**

* Dropdown structure exists
* Only Minx City appears for now
