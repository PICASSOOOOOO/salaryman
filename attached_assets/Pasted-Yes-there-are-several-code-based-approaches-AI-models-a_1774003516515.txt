Here are the best ways to help your AI build roads:
1. Procedural Road Generation (Code & Algorithms)
These approaches use mathematical rules to grow roads, similar to how Cities: Skylines generates road meshes.
Deamtech Splines (Unity API): A flexible component system that allows you to create nodes at runtime, connect them, and spawn road meshes along the path using C#.
Shape Grammar & L-Systems: Early, highly effective procedural methods that use defined rules to grow networks. These are often used for grid-based or organic city layouts.
Skeleton Algorithm: A computer graphics technique that can automatically generate a road network by identifying the "skeleton" of a area, taking into account terrain, buildings, and water.
Graph-based Modeling: Creating a graph structure where nodes are intersections and edges are roads. You can grow this graph using rules to densify the road network.

2. AI-Powered Road Generation Models
These models use machine learning to generate realistic road layouts based on existing data.
Neural Turtle Graphics (NTG): A generative AI model by NVIDIA Research that generates new city road layouts by iteratively creating nodes and edges based on training data.
CityGenAgent: A natural language-driven framework that uses Reinforcement Learning (RL) to generate valid 3D city layouts, allowing for natural language instructions.
GAN-based Networks: Generative Adversarial Networks (GANs) are used to train on real-world urban maps (such as OpenStreetMap) to synthesize new, realistic road network layouts.
Proc-GS (Procedural + Gaussian Splatting): A method that integrates procedural code into 3D Gaussian Splatting to generate high-fidelity road networks and building layouts.

3. Practical Tools and Frameworks
iPCC (Interactive Procedural City Creator): A tool built for Unreal Engine that can generate realistic road networks, bridges, and intersections, allowing for interactive tweaking.
Claude Code + Three.js: Road building games have been created using Claude Code to handle Three.js scene setup and A* pathfinding for road traffic.
OpenStreetMap (OSM) Data: You can use data directly from OpenStreetMap to reconstruct real-world road networks in simulation engines.

Summary of Approach
To build a system like Cities: Skylines, you typically need a two-part AI system:
Layout Generation (Procedural/AI): Determines where the roads go (nodes and edges).
Mesh Generation (Splines/Procedural): Determines how the road looks (bending, elevating, upgrading).
