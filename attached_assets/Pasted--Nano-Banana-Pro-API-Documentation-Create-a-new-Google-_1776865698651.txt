# Nano Banana Pro API Documentation

> Create a new Google Nano Banana Pro image generation task

## Overview

This document describes how to use the Nano Banana Pro model for content generation. The process consists of two steps:
1. Create a new Google Nano Banana Pro image generation task
2. Query task status and results by task ID

## Authentication

All API requests require a Bearer Token in the request header:

```
Authorization: Bearer YOUR_API_KEY
```

Get API Key:
1. Visit [API Key Management Page](https://apipass.dev/app/api-keys) to get your API Key
2. Add to request header: `Authorization: Bearer YOUR_API_KEY`

---

## 1. Create Task

### API Information
- **URL**: `POST https://api.apipass.dev/api/v1/jobs/createTask`
- **Content-Type**: `application/json`

### Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| model | string | Yes | The model name to use Example: `"google/nano-banana-pro"` |
| callBackUrl | string | No | Callback URL for task completion notifications Example: `"https://your-domain.com/api/callback"` |

### Model Parameter

The `model` parameter specifies which AI model to use for content generation.

| Property | Value | Description |
|----------|-------|-------------|
| **Format** | `google/nano-banana-pro` | The exact model identifier for this API |
| **Type** | string | Must be passed as a string value |
| **Required** | Yes | This parameter is mandatory for all requests |

> **Note**: The model parameter must match exactly as shown above. Different models have different capabilities and parameter requirements.

### Callback URL Parameter

The `callBackUrl` parameter allows you to receive automatic notifications when your task completes.

| Property | Value | Description |
|----------|-------|-------------|
| **Purpose** | Task completion notification | Receive real-time updates when your task finishes |
| **Method** | POST request | The system sends POST requests to your callback URL |
| **Timing** | When task completes | Notifications sent for both success and failure states |
| **Content** | Query Task API response | Callback content structure is identical to the Query Task API response |
| **Parameters** | Complete request data | The `param` field contains the complete Create Task request parameters, not just the input section |
| **Optional** | Yes | If not provided, no callback notifications will be sent |

**Important Notes:**
- Generation typically takes 10-30 seconds for high-quality output
- If callBackUrl is not provided, use Query Task API to poll for status
- Maximum image size for reference images is 10MB

### input Object Parameters

#### prompt
- **Type**: `string`
- **Required**: Yes
- **Description**: Text description of the image you want to generate

#### aspect_ratio
- **Type**: `enum: ['LANDSCAPE', 'PORTRAIT']`
- **Required**: Yes
- **Description**: Aspect ratio of the generated image

#### images
- **Type**: `array`
- **Required**: No
- **Description**: Reference images for image-to-image generation (base64 or URL)

### Request Example

```json
{
  "model": "google/nano-banana-pro",
  "callBackUrl": "https://your-domain.com/api/callback",
  "input": {}
}
```

### Response Example

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_12345678"
  }
}
```

### Response Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| code | integer | Status code, 200 for success |
| message | string | Response message |
| data.taskId | string | Task ID for querying status |

### Callback Notifications

#### Success Callback Example

```json
{
  "code": 200,
  "data": {
    "taskId": "task_12345678",
    "state": "success",
    "completeTime": 1755599644000,
    "costTime": 15,
    "createTime": 1755599634000,
    "model": "google/nano-banana-pro",
    "resultJson": "{\"resultUrls\": [\"https://example.com/generated-image.jpg\"]}"
  },
  "msg": "Task completed successfully."
}
```

#### Failure Callback Example

```json
{
  "code": 501,
  "data": {
    "taskId": "task_12345678",
    "state": "fail",
    "failCode": "500",
    "failMsg": "Generation failed"
  },
  "msg": "Task failed."
}
```

## 2. Query Task

### API Information
- **URL**: `GET https://api.apipass.dev/api/v1/jobs/recordInfo`
- **Parameter**: `taskId` (passed via URL parameter)

### Request Example

```
curl -X GET "{BASE_URL}/api/v1/jobs/recordInfo?taskId=task_12345678" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response Example

```json
{
  "code": 200,
  "data": {
    "taskId": "task_12345678",
    "state": "success",
    "resultJson": "{\"resultUrls\": [\"https://example.com/generated-image.jpg\"]}"
  }
}
```

### Response Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| code | integer | Status code, 200 for success |
| data.taskId | string | The task ID |
| data.state | string | Current state of the task |
| data.resultJson | string | JSON string containing resultUrls when successful |

### State Values

- waiting - Task is waiting to be processed
- queuing - Task is in queue
- generating - Generation in progress
- success - Generation completed successfully
- fail - Generation failed

---

## Usage Flow

1. **Create Task**: Call `POST https://api.apipass.dev/api/v1/jobs/createTask` to create a generation task
2. **Get Task ID**: Extract `taskId` from the response
3. **Wait for Results**: 
   - If you provided a `callBackUrl`, wait for the callback notification
   - If no `callBackUrl`, poll status by calling `GET https://api.apipass.dev/api/v1/jobs/recordInfo`
4. **Get Results**: When `state` is `success`, extract generation results from `resultJson`

## Error Codes

| Status Code | Description |
|-------------|-------------|
| 200 | Request successful |
| 400 | Invalid request parameters |
| 401 | Authentication failed, please check API Key |
| 402 | Insufficient account balance |
| 404 | Resource not found |
| 422 | Parameter validation failed |
| 429 | Request rate limit exceeded |
| 500 | Internal server error |
