---
name: Ten-minute feature checks
description: User-requested cadence for project-wide regression and collision testing.
---

The user wants all supported features tested every ten minutes to detect collisions and keep them working reliably.

**Why:** the user asked for this as a standing project rule.

**How to apply:** define the tested feature inventory, prevent overlapping runs, and report uncovered or live-only behavior. Never promise that tests prove perfect 100% reliability.
