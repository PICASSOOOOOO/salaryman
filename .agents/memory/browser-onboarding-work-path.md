---
name: Browser onboarding work paths
description: Browser onboarding is a lightweight work-path choice, separate from the downloadable game's fictional immigration flow.
---

The browser product must present two plain-language paths: start a real business or look for work. Do not expose the internal `unemployed` status label or fictional/game company setup in this web flow.

**Why:** SALARYMAN's browser purpose is practical work: create jobs, find work, or hire. Fictional business and immigration concepts belong only to the downloadable game.

**How to apply:** Keep onboarding at `/onboarding`, persist the selected path server-side, and use “LOOKING FOR WORK” in user-facing copy even if the API retains `unemployed` as its compatibility value.
