The user wants five clear attribute trees with spendable points: Body, Reflexes, Technical Ability, Intelligence, and Cool. Each tree should have more than 50 skills, with tiered abilities and cooldowns. The earlier stealth, attack, defense, repair, mechanics, computer, corporate-survival, and tycoon concepts should be represented within these five attributes, not as separate tree names. Items degrade and need repair; repair/maintenance is a major gameplay system.

Create useful, unique equipment with several levels and applications. Initial item families are water, power, defense, safety, and health, alongside office maintenance/repair tools, weapons, technology, replicant energy equipment, and power-related items.

Use the five attribute names as the visible labels; avoid codenames and title-plus-subtitle pairs.

**Why:** The user explicitly defined the scope, tree categories, size, item priorities, and progression style for the native game.

**How to apply:** Extend existing skill, item, inventory, battery, condition, and repair systems rather than creating parallel catalogs. Keep power/utility economics authoritative; progression points must not be client-forged.
