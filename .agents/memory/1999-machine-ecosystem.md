The 1999 workstation should support Akai MPC, Korg, Boss, Roland SP-404MKII, Teenage Engineering OP-1, and similar machines, with their sounds.

**Why:** the user asked for a balanced system that can handle all of these machines.

**How to apply:** keep machine support modular and resource-aware. Clearly distinguish hardware-firmware emulation from original recreations, sample-based instruments, and companion plugins; one model's support does not represent an entire brand.
