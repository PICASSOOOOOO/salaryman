name: SampQOL reference boundary
description: Licensing and compatibility constraints for the SampQOL OS firmware mod supplied as a 1999 feature reference.
---

SampQOL OS v0.2.0 is a compiled ARM64 mod for MPC Sample firmware 1.3.0, not a browser plug-in. Its license permits personal use, study, decompilation, and modification, but prohibits distributing the original package or modified versions and asks users to share the official release link instead. Do not bundle its binary, scripts, splash art, manual, screens, layouts, or copied text into SALARYMAN. Reimplement compatible workflows as original browser code; describe them as 1999 features, not as the firmware mod running in the app.

**Why:** the mod is hardware- and firmware-specific, while the 1999 sampler is a browser workstation; redistributing the package would violate its stated license.

**How to apply:** keep the existing 16-pad / eight-lane project model, adapt documented workflows to those limits, and link to the official release when attribution or a source reference is useful.
