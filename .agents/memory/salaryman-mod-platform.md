description: Product intent and safety boundary for user-created SALARYMAN feature add-ons.
---

“Firmware” means installable SALARYMAN game-feature add-ons, including 1999 presets and feature customizations, not physical-device firmware. PABLO DECK is the home for creating mods, firmware packages, apps, and games, with SALARYMAN-hosted projects and previews. Keep the server authoritative for shared multiplayer state. User-created app/game code may run only in a restricted client-side sandbox; never execute arbitrary uploads on shared SALARYMAN servers or grant projects ambient access to user accounts, internal APIs, or the parent app.

The in-world modding entry points are computer/terminal and replicant-repair shops. Browser creator tools and hosted projects belong inside PABLO DECK, not under account Settings.

The source repository is intended to remain open under GPL-3.0-only. Reuse of bundled art, audio, video, fonts, and other media still depends on each asset's license.

**Why:** The user wants community members to build mods, firmware, apps, and games for SALARYMAN, and explicitly placed those creation tools inside PABLO DECK.

**How to apply:** Use declarative packages for installable game customizations and isolated static hosting for apps/games. Keep arbitrary server execution and client authority over multiplayer state disabled. Keep fictional shop interactions separate from browser account permissions and review workflows. Track media rights separately from source-code licensing.
