The user wants the entire 1999 workstation to be usable as a plugin in Ableton, not only the FM-1 emulator.

**Why:** the user selected “Entire 1999 workstation” when asked which 1999 instrument Ableton should host.

**How to apply:** treat Ableton support as a separate native plugin target for the full 1999 workstation. An FM-1-only VST or an embedded browser player does not satisfy this request.
