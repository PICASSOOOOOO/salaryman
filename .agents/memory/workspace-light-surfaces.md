---
name: Workspace light surfaces
description: SALARYMAN's practical workspace chrome and desktop client use a white navy/ocean-blue system distinct from immersive Pablo nebula routes.
---

The practical workspace surfaces are intentionally light: shared desktop/mobile chrome, the mobile workstation, account summary sheet, and desktop client landing page use white backgrounds, navy text, ocean-blue actions, and cool gray borders. Immersive Pablo nebula presentation remains a separate visual surface.

**Why:** The browser business workspace and downloadable-client handoff need to feel like one professional product, while the Pablo front door remains an expressive assistant surface.

**How to apply:** When adding practical workspace UI, use the existing white surface tokens/classes rather than dark terminal styling. Do not alter the Pablo orb or voice presentation unless the user explicitly asks for that surface.
