---
name: Pablo creation workspace
description: Product direction for a persistent, visual project-building area inside Pablo.
---

Pablo should have a dedicated creation workspace where users can organize and build apps, websites, games, and income ventures. The work area should connect SALARYMAN's internal tools with external references and services, and make project work visible and interactive instead of relying on long chat threads.

**Why:** the user explicitly wants a Replit-like creation area inside Pablo, combining internal work with external efforts; they also prefer minimal copy and interactive visual surfaces site-wide.

**How to apply:** keep projects and drafts persistent, show generated work in an editable/previewable area, and require deliberate review before external publishing, deployment, database changes, or financial settlement. Current income mode is review-only until a real revenue source is verified; any future real payout is opt-in for the business owner, never an employee capability.
