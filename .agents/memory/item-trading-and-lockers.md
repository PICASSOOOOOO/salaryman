description: User-defined rules for item shops, player listings, NPC trading, and locker security.

SALARYMAN item shops must buy and sell any catalog item, with a markup on shop buybacks. Player listings are character-owned and must escrow inventory until sale or cancellation. NPCs should be able to trade and carry discoverable rare items. Personal and public lockers must not be breakable into.

**Why:** the user specified these as core rules for the locker/inventory expansion.

**How to apply:** preserve these rules when extending the in-game economy, NPC inventory, marketplace settlement, and locker access.
