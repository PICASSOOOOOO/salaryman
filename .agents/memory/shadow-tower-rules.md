name: Shadow Tower rules
description: Index of shared floor geometry, assignment, access, capacity, and art constraints.

Treat each playable floor as one shared contract: listings, rendered geometry, collision, assignments, capacity, upgrades, access, service counters, and prices must agree.

**Why:** Independent floor rules can create units that are listed but not playable, inaccessible, or priced inconsistently.

**How to apply:** Start with the floor authority note, then open the focused note for hierarchy, ownership, shells, art, services, or access.

- [Shared floor authority](shadow-tower-floor-authority.md) — listings and playable space use one contract.
- [Floor hierarchy](shadow-tower-hierarchy.md) — sale and reserved floor ranges.
- [Organization office assignment](organization-office-assignment.md) — shared org suites and separately funded employee stations.
- [Named Tower art](shadow-tower-named-art.md) — finished spaces use the named asset manifest.
- [Floor defaults](tower-floor-defaults.md) — office addresses, merging, and paid fit-outs.
- [Physical floor shells](tower-physical-floor-shells.md) — every elevator stop has a shell.
- [Service scopes](tower-service-scopes.md) — fixed-suite tenants own service counters.
- [Office access](tower-office-access.md) — use existing floor-level access authority.
