---
name: Tower pixel-art visual quality
description: Visual-quality requirements for the Tower side-view prototype.
---

Pixel art is welcome for the Tower side-view, but the result must remain polished and recognizable. Do not fill the scene with generic boxes or computer icons as stand-ins for objects, project every simulation object without visual curation, or use a mismatched character atlas frame. Preserve the existing Godot renderings where appropriate, and keep the default 3D game intact.

**Why:** The owner explicitly rejected the rough prototype visuals and asked for quality while keeping a pixel-art direction.

**How to apply:** Before revising the side-view, audit available Godot and pixel-art assets, choose the correct character appearance and animation, curate visible objects, and review the rendered result rather than relying only on a code check.
