---
name: No CRT visual language
description: The durable visual direction after retiring SALARYMAN's CRT presentation.
---

Use a modern dark interface with Inter for UI/display text and Fira Code only where data or code benefits from monospace. Do not reintroduce CRT scanlines, phosphor glow/tints, flicker, animated grain, chromatic aberration, glitch overlays, or VT323/Share Tech Mono presentation.

**Why:** The CRT treatment was explicitly rejected as outdated. The living Pablo/Mila nebula and game artwork should remain vivid without a simulated display layer over them.

**How to apply:** New and revised surfaces should use clean dark-slate cards, restrained cyan/purple accents, and direct artwork. Preserve functional terminal/game metaphors, but render them without fake-monitor effects.
