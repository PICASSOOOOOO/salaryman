# Candidate C — adult-proportion direction

Run from the repository root:

```sh
godot --path godot/office-client res://review/adult_salaryman_candidate_c.tscn
```

Use ←/→ to turn, R to reset, and Esc to exit. This review uses the adult-proportioned
`realistic_salaryman_preview.glb`, hides its glasses meshes, freezes the source
standing pose with arms lowered, and scales only the head joint to 0.80. Small
review-only shirt/tie panels keep the formal outfit readable at gameplay scale.
**UNAPPROVED REVIEW ART**; production assets, roster, and animation clips are
unchanged.
